# Privacy Policy

**Project Environment Manager** - Last Updated: May 2026

## Overview

Project Environment Manager ("the Extension") is committed to protecting your privacy. This Privacy Policy explains what information the Extension collects, how it uses that information, and your rights.

## Information We Collect

### User Data (Stored Locally)
- Project names and environment URLs
- Environment configuration (colors, status)
- Badge customization settings

**Where It's Stored:** Chrome's local storage and sync storage (if enabled)

### No Server Collection
We do **NOT** collect, send, or store any data on external servers. All information remains on your device.

### Technical Information
We do **NOT** collect:
- Browsing history
- Personal information
- Analytics or usage data
- IP addresses
- Device identifiers

## How We Use Information

Your project data is used exclusively to:
1. Display environment indicators on webpages
2. Enable environment switching functionality
3. Provide data export/import features
4. Maintain user preferences and settings

## Data Storage & Security

- All data is stored in your Chrome browser's storage
- Data is NOT encrypted (relies on Chrome's built-in security)
- Data persists even after browser restart (unless you clear browser data)
- Data is deleted when you uninstall the Extension or clear Chrome data

## Chrome Sync

If you enable Chrome Sync:
- Your project data will sync across Chrome profiles on signed-in devices
- Data is encrypted in transit
- Google's privacy policy applies to synced data

## Third-Party Services

The Extension does **NOT**:
- Use third-party analytics
- Send data to external services
- Use tracking pixels or cookies
- Embed third-party scripts

## Permissions Explained

| Permission | Purpose | Data Collected |
|-----------|---------|-----------------|
| `storage` | Store projects locally | Project names, URLs, colors |
| `activeTab` | Detect current tab URL | Current page URL (not stored) |
| `scripting` | Inject floating badge | None |
| `webNavigation` | Track page changes | None |
| `<all_urls>` | Work on all websites | None |

## Data Removal

To delete all Extension data:
1. Open Extension settings
2. Click "🗑️ Clear All Data"
3. Confirm deletion

Or uninstall the Extension from Chrome settings.

## Your Rights

You have the right to:
- Access your data (export it anytime)
- Delete your data (clear all or uninstall)
- Understand what data is collected
- Know how data is used

## Changes to This Policy

We may update this Privacy Policy occasionally. Changes will be reflected in the Extension version notes.
